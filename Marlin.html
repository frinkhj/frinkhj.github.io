Project: 3D Printer firmware

Written in C++ for a personal project

About the Project

This is a long term personal project of mine that is focused on reviving an older 3D Printer I received in high school. As part of this project I have update the motherboard of the printer and have modified and used the open-source firmware known as Marlin that can be found on GitHub. I have made small contribution to the open-source project such as making notes of compatibility issues between hardware and firmware versions. From this I gained experience with open-source Projects and with making hardware work with firmware. The firmware is written in C++ and the language the printer responds to is called g-code.

Features

  • Updated motherboard
  • Modified and uploaded correct firmware
  • Installed new hardware and tuned printer to work as expected
